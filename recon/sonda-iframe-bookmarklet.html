¿Se puede manejar la plataforma desde un iframe?

Arrastra este botón a tu barra de favoritos:

Sonda iframe

Pesa 17.4 KB. No lo pulses desde aquí: solo funciona en la plataforma.

  1. Abre en Classroom Live la pantalla de asistencia diaria por asignatura y déjala cargada, con sesión iniciada.
  2. Pulsa el favorito Sonda iframe: aparece un panel abajo a la derecha.
  3. Pulsa Medir y espera unos segundos (carga la misma pantalla dos veces dentro de un iframe escondido).
  4. Pulsa Copiar resultado y pega el JSON en el chat.

Qué está midiendo. Hoy el favorito de asistencia te obliga a poner fecha, hora, curso y asignatura a mano, y por eso marcar en planilla-app no ahorra tiempo. El flujo completo ya sabe recorrer el filtro solo, pero cada paso recarga la página y un favorito no sobrevive una recarga. Si el script se queda en la página de arriba y mete la plataforma en un iframe, el que navega es el iframe y el script de arriba no se recarga nunca.

Con fetch no alcanza para la asistencia: hay que acabar en una pantalla de verdad, con sus scripts vivos, porque vos tenés que revisar y pulsar Guardar. Si se reemplaza el HTML a mano, los scripts no se vuelven a ejecutar y el Guardar deja de funcionar. El iframe no tiene ese problema.

Solo mide. No llama a __doPostBack ni una vez, no envía ningún formulario, no toca ningún control y no deja el iframe puesto. Lo único que pide a la red es la misma dirección que ya estás viendo. npm test comprueba las cinco cosas, y que romper cualquiera se note.
