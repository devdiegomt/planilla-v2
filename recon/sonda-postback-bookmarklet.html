¿Se puede hacer un postback sin recargar?

Arrastra este botón a tu barra de favoritos:

Sonda postback

Pesa 15.0 KB. No lo pulses desde aquí: solo funciona en la plataforma.

  1. Abre en Classroom Live cualquier pantalla con datos — la matriz de actividades, la asistencia, la que sea — y déjala cargada.
  2. Pulsa el favorito Sonda postback: aparece un panel.
  3. Pulsa Medir y espera un segundo.
  4. Pulsa Copiar resultado y pega el JSON en el chat.

Qué está midiendo. Hoy un favorito solo sirve para lo de un golpe, porque cada postback recarga la página y el favorito no se vuelve a inyectar. Pero eso vale mientras el postback navegue: si el mismo envío se hace con fetch y la página no se recarga, el script no muere. Esta sonda mide si el servidor colabora con eso.

Si el veredicto dice SE PUEDE, Tampermonkey deja de hacer falta para el extractor de actividades, el de historial y el autofill de la matriz. Si dice que no, queda confirmado que la extensión es obligatoria para esos tres, y dejamos de darle vueltas.

Solo mide. Manda UN envío de "vuelve a dibujar la misma página" —sin ningún control, ni siquiera Consultar—, lee lo que vuelve y lo tira. No toca la pantalla, no guarda nada y tiene una lista negra que le impide disparar Guardar, Importar, Actualizar, Editar o Eliminar.
